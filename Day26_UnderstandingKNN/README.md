# Day 26: k-Nearest Neighbors (k-NN) Classifier

---

## 📌 Objective:

Understand and implement the k-Nearest Neighbors (k-NN) algorithm.
Apply k-NN to the Breast Cancer Wisconsin dataset.
Visualize decision boundaries and evaluate model performance.

---
## 📚 Topics Covered:

Theory behind k-NN
Preprocessing Breast Cancer Dataset (feature selection and scaling)
Model training with KNeighborsClassifier from Scikit-Learn
Visualizing decision boundaries using matplotlib
Hyperparameter tuning (k value selection)
Evaluating model accuracy and performance metrics

---

## 🛠️ Tools & Libraries:

Pandas

## 🔍 Key Highlights:

Feature Selection: Focused on two features (mean radius and mean texture) for visualization purposes.
Scaling: Standardized features using StandardScaler.
k-NN Implementation: Tried various values of k (e.g., 1, 3, 5, 7, 9) and plotted the decision boundaries.
Evaluation: Checked accuracy, confusion matrix, and compared how different k values affect model performance.
Decision Boundary Visualization: Used meshgrid to create smooth decision boundary plots for better interpretability.
