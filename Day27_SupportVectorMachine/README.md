## 🌟 What is SVM?

SVM tries to find the optimal hyperplane that best separates classes in the feature space. It maximizes the **margin**, which is the distance between the hyperplane and the nearest data points from each class, called **support vectors**.

When the data isn't linearly separable, SVM uses the **Kernel Trick** to transform it into higher dimensions where it becomes linearly separable!
